# Reference images

The visual references that shaped Diwali House (`design/visual-direction.md` § 1) live here on the owner's machine, but are **not in the repository**: they are third-party images whose sources and licences are unknown (`design/asset-manifest.md` § Reference material). They are never shipped, and they are not distributed with this code.

If you're working on the art direction, ask the project owner for copies and put them in this folder. Git ignores everything here except this file.
